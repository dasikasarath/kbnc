🎓 Student Management System – Spring Boot JWT Security
📌 Overview

This project is a Student Management System built using Spring Boot with JWT Authentication & Authorization.
It demonstrates how to secure REST APIs using Spring Security, manage users with JPA, and control access based on roles.

Features
🔐 JWT Authentication

Secure login using JSON Web Tokens
Token-based stateless authentication
👥 Role-Based Authorization
ROLE_USER → View student data
ROLE_ADMIN → Create, update, delete students


🗂️ Student Management

Add student
View student list
Update student details
Delete student


🛡️ Spring Security Integration
Custom authentication filter
Password encryption using BCrypt


💾 JPA & Database
Uses Spring Data JPA
CRUD operations with repository layer

Tech Stack
Java
Spring Boot
Spring Security
JWT (JSON Web Token)
Spring Data JPA
MySQL 
HTML, CSS, JavaScript (Frontend)


Future Improvements
Refresh Token implementation
Redis caching for token blacklist
Docker support
